Requirements

  • CMake 3.20 or newer
  • Ninja
  • GCC/G++ with C++11 support for the supplied test program
  • FreeGLUT 3.0.0
  • OpenGL
  • Windows x64 for the supplied DLL/test commands

The repository includes the FreeGLUT and media dependencies used by the supplied project and test setup.
