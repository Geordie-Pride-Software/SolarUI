Input Bridge

SolarUI provides an input bridge so FreeGLUT applications can forward mouse and keyboard events into the library.

Mouse

void solInputBridge_MouseMove(int x, int y);
void solInputBridge_MouseButton(int button, int state, int x, int y);

Keyboard

void solInputBridge_KeyDown(unsigned char key, int x, int y);
void solInputBridge_KeyUp(unsigned char key, int x, int y);
void solInputBridge_SpecialKey(int key, int x, int y);
void solInputBridge_SpecialKeyUp(int key, int x, int y);

These functions can be connected to the application's GLUT callbacks.
