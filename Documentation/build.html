Building SolarUI

Build the DLL

Run these commands from the src folder:

cmake -S . -B build_dll -G "Ninja" -DSOLARUI_BUILD_SHARED=ON
cmake --build build_dll

This builds SolarUI as a shared library and produces the import library used by the supplied test command.

Compile test.cpp

From the src folder, enter test:

cd test
g++ -std=c++11 -I../src/external/freeglut-3.0.0/include test.cpp libSolarUI.dll.a -L../src/external/freeglut-3.0.0/lib/x64 -lfreeglut -lopengl32 -lglu32 -lgdi32 -lwinmm -o test.exe

Run the test

./test.exe
Windows DLLs: The required 64-bit DLLs need to be available to the executable at runtime. Mixing 32-bit and 64-bit binaries can cause Windows error 0xc000007b.
